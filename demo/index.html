What is head-scroll.js?

head-scroll.js uses your webcam and MediaPipe FaceMesh to track the position of your nose tip (landmark #4) in real time. When your head tilts past the configured threshold, it scrolls any element — or the whole window.

Calibration

Auto-calibration samples 90 frames (~3 seconds) after your face is first detected, computing your personal neutral Y baseline. Recalibrate any time you change your seating position.

Sensitivity

The threshold option controls the dead zone — how much tilt is needed before scrolling begins. The maxSpeed option caps the scroll rate. Speed is proportional to tilt angle.

Privacy

All processing happens on-device in the browser. No video frames leave your machine. MediaPipe runs as a WebAssembly module loaded from CDN.

Use Cases

Hands-free recipe browsing. Accessibility for users with motor impairments. Touch-free kiosk displays. Scrolling through word-game cards mid-round without touching the screen.

Browser Support

Chrome 60+ · Edge 79+ · Firefox 36+ · Safari 11+

Examples

MINIMAL

const hs = new HeadScroll();
hs.start(); // camera → auto-calibrate → scroll window

SCROLL A SPECIFIC ELEMENT

const hs = new HeadScroll({
  target:    document.getElementById('my-card'),
  threshold: 0.03,  // more sensitive
  maxSpeed:  12,    // slower
});
hs.start();

CALLBACKS — GAME / REACT INTEGRATION

const hs = new HeadScroll({
  showHUD: false,
  onCalibrated: (neutralY) => console.log('Ready! Y=', neutralY),
  onFrame: ({ scrolling }) => {
    // scrolling === 'up' | 'down' | 'none'
    if (scrolling === 'down') nextCard();
    if (scrolling === 'up')   prevCard();
  },
  onStatus: (type, msg) => updateUI(type, msg),
});
hs.start();

EYE GAZE MODE

// Scroll by looking up / down instead of tilting your head
const hs = new HeadScroll({
  eyeGaze:       true,   // enable iris tracking
  gazeThreshold: 0.08,  // gaze dead-zone (0–1)
});
hs.start();

// onFrame receives gazeRatio instead of noseY
onFrame: ({ gazeRatio, delta, scrolling }) => { /* ... */ }

MANUAL CALIBRATION

const hs = new HeadScroll({ autoCalibrate: false });
await hs.start();

document.getElementById('cal-btn').addEventListener('click', async () => {
  const y = await hs.calibrate();
  console.log('Neutral Y:', y);
});
// API REFERENCE

Options

OptionTypeDefaultDescription
targetElementnullElement to scroll. null = window.
thresholdnumber0.04Dead-zone (0–1). Smaller = more sensitive.
maxSpeednumber18Max scroll speed in px/frame.
calibrationFramesnumber90Frames sampled during calibration (~3s at 30fps).
autoCalibratebooleantrueAuto-calibrate on first face detection.
showHUDbooleantrueShow draggable status widget.
mediapipeCDNstringjsdelivrOverride CDN for self-hosting MediaPipe.
eyeGazebooleanfalseScroll by looking up/down instead of head tilt. Uses iris landmarks — requires refineLandmarks.
gazeThresholdnumber0.08Gaze dead-zone (0–1). Used when eyeGaze is true.
onStatusfunctionnull(type, msg) — status change callback.
onFramefunctionnull({ noseY|gazeRatio, neutralY, delta, scrolling }) — per-frame callback.
onCalibratedfunctionnull(neutralY) — fires after calibration.

Methods

MethodReturnsDescription
start()Promise<void>Request camera, load model, begin tracking.
stop()voidStop tracking, release camera, remove HUD.
calibrate()Promise<number>Trigger calibration. Resolves with neutralY.
setNeutralY(y)voidManually override neutral position.
