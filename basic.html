What is head-scroll.js?

head-scroll.js uses your webcam and MediaPipe FaceMesh to track the position of your nose (landmark #4) in 3D space. When your head tilts up or down beyond the configured threshold, it scrolls any element — or the whole window.

How does calibration work?

During calibration the library samples 90 frames (~3 seconds) and computes the average nose Y position. This becomes your personal neutral baseline. Recalibrate any time you change your sitting position.

Privacy & Security

All video processing happens on-device in the browser. No frames are sent to any server. The camera stream never leaves your machine.

Use Cases

Hands-free recipe reading in the kitchen. Accessibility for users with motor impairments. Touch-free kiosk interfaces. Scrolling through word-game cards without touching the screen mid-game.

Browser Support

Works in any browser that supports getUserMedia over a secure context (HTTPS or localhost): Chrome 60+, Edge 79+, Firefox 36+, Safari 11+.

Examples

From zero to advanced in four snippets.

MINIMAL — SCROLL WINDOW

const hs = new HeadScroll();
hs.start(); // asks for camera, auto-calibrates, starts scrolling window

SCROLL A SPECIFIC ELEMENT

const hs = new HeadScroll({
  target:    document.getElementById('my-card'),
  threshold: 0.03,   // more sensitive
  maxSpeed:  12,     // slower scroll
});
hs.start();

CALLBACKS — REACT / GAME INTEGRATION

const hs = new HeadScroll({
  showHUD: false,
  onCalibrated: (neutralY) => {
    console.log('Ready! Neutral Y:', neutralY);
  },
  onFrame: ({ delta, scrolling }) => {
    // scrolling === 'up' | 'down' | 'none'
    if (scrolling === 'down') nextCard();
    if (scrolling === 'up')   prevCard();
  },
  onStatus: (type, msg) => updateUI(type, msg),
});
hs.start();

MANUAL CALIBRATION TRIGGER

// Disable auto-calibrate, trigger manually
const hs = new HeadScroll({ autoCalibrate: false });
await hs.start();

document.getElementById('cal-btn').addEventListener('click', async () => {
  const y = await hs.calibrate();
  console.log('Neutral Y set to', y);
});
// API REFERENCE

Options

Pass an options object to the constructor.

OptionTypeDefaultDescription
targetElementnullElement to scroll. null = window.
thresholdnumber0.04Dead-zone size (0–1). Smaller = more sensitive.
maxSpeednumber18Maximum scroll speed in px/frame.
calibrationFramesnumber90Frames to sample during calibration (~3 sec at 30fps).
autoCalibratebooleantrueCalibrate automatically on first face detection.
showHUDbooleantrueShow draggable status widget.
mediapipeCDNstring"jsdelivr…"Override CDN for self-hosting MediaPipe.
onStatusfunctionnullCalled on status change: (type, message).
onFramefunctionnullCalled every frame: ({ noseY, neutralY, delta, scrolling }).
onCalibratedfunctionnullCalled after calibration: (neutralY).
